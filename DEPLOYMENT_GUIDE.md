# Полное руководство по переносу iBOX Academy на ваш сервер

## 1. Подготовка окружения
Приложение построено на **React (Vite)** + **Firebase**. Для работы на своем сервере вам не нужно настраивать базу данных SQL, так как данные хранятся в облаке Google Firebase (Firestore). Это позволяет экономить на ресурсах сервера.

### Системные требования:
- Node.js 18+ 
- Установленный `npm` или `yarn`

## 2. Настройка Firebase (Обязательно)
Для того чтобы данные сохранялись именно в вашу базу:
1. Зайдите в [Firebase Console](https://console.firebase.google.com/).
2. Создайте проект (если еще нет).
3. В разделе **Project Settings** найдите **Firebase SDK snippet** (выберите Web App `</>`).
4. Скопируйте объект `firebaseConfig`.
5. В папке проекта на сервере найдите файл `src/lib/firebase.ts` и замените конфиг на ваш.
6. **Важно:** В разделе **Build -> Firestore Database** нажмите "Create database" и выберите регион (рекомендуем eur3).

## 3. Поддержка тяжелых файлов (15МБ+)
Поскольку Firestore имеет лимит 1МБ на документ, вы **не сможете** загружать видео 15МБ прямо "в код" курса.
**Как сделать правильно:**
1. Включите **Firebase Storage** в консоли Firebase.
2. В файле `firestore.rules` добавьте правила для Storage (чтобы админы могли загружать файлы).
3. Или просто загружайте файлы на свой **Bitrix24 Диск** или **Google Drive**, копируйте "Прямую ссылку" и вставляйте её в поле "Медиа-ресурс" при создании курса. Это самый дешевый и надежный способ.

## 4. Сборка и Деплой
Находясь в папке проекта на сервере:
```bash
# 1. Установка зависимостей
npm install

# 2. Сборка проекта
npm run build
```
После этого в папке `dist` появятся готовые файлы. Эти файлы нужно отдать вашим веб-сервером (Nginx или Apache).

### Пример конфига Nginx:
```nginx
server {
    listen 80;
    server_name academy.yourcompany.ru;
    root /path/to/your/app/dist;
    index index.html;

    location / {
        try_files $uri $uri/ /index.html;
    }
}
```

## 5. Интеграция в Битрикс24 (Локальное приложение)
1. В Битрикс24 перейдите в **Маркет -> Разработчикам -> Другое -> Локальное приложение**.
2. Тип: **Статическое**.
3. Укажите URL вашего сервера (например: `https://academy.yourcompany.ru`).
4. Нажмите "Сохранить". Теперь iBOX Academy доступна внутри вашего портала.

## 6. Как работают роли и API
- Ключ API (`GEMINI_API_KEY`) должен быть прописан в переменных окружения сервера (`.env`) или прямо в коде `aiService.ts` (не рекомендуется для публичных проектов).
- Все действия пользователей (история, результаты) записываются в Firestore мгновенно.
- Если вы хотите изменить промпты, используйте **Админ-панель** внутри приложения (она сохраняет настройки в коллекцию `settings`).
