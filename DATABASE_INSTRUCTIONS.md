# Подробная инструкция iBOX Academy (База Данных и Сервер)

## 1. Подключение к Google Cloud / Firebase
Ваше приложение использует **Firebase (Google Cloud)** для хранения данных. Это обеспечивает максимальную скорость и безопасность без необходимости настраивать свой сервер базы данных.

### Как задействовать базу:
1. Перейдите в [Firebase Console](https://console.firebase.google.com/).
2. Раздел **Build -> Firestore Database**.
3. Если там пусто — это нормально! Firestore создает коллекции автоматически, как только приложение записывает первый документ.
4. Выполните вход в приложение под почтой `oap.ibox.company@gmail.com`. Скрипт в `App.tsx` автоматически инициализирует начальные курсы и глоссарий в вашей базе.

## 2. Управление Ролями (Доступ)
Все права хранятся в коллекции `roles`.
- **admin**: Полный доступ. Может менять промпты ИИ и удалять любые курсы.
- **manager**: Видит только сотрудников своего отдела в разделе "Аналитика".
- **employee**: Видит только каталог и назначенные ему курсы.

**Как выдать роль вручную:**
В Firestore создайте документ в коллекции `roles`, где **Document ID** = UID пользователя из раздела Authentication. Поле: `role` (string) = "admin".

## 3. Интеграция в Bitrix24
Для встраивания в Битрикс:
1. Соберите приложение (`npm run build`).
2. Загрузите содержимое папки `dist` на любой статический хостинг (Firebase Hosting, GitHub Pages, или ваш сервер).
3. В Битрикс24 добавьте "Приложение -> Добавить приложение -> Для личного использования".
4. Укажите URL загруженного приложения.
5. Приложение адаптировано под iframe (инициалы, прокрутка, навигация).

## 4. Использование API Ключей и Стоимость
- **GEMINI_API_KEY**: Используется для генерации текстов, курсов и работы Тьютора.
- **Масштабирование**: Приложение спроектировано так, чтобы работать по модели Pay-as-you-go. Вы платите только за реальные запросы к ИИ и чтение базы.
- **Меньшая стоимость**: Для экономии в `aiService.ts` установлена модель `gemini-1.5-flash` (она быстрее и значительно дешевле `pro` при том же качестве для текстов).

## 5. Системные Промпты
Теперь вы можете менять поведение ИИ прямо в интерфейсе!
1. Зайдите во вкладку **Админ-панель -> ИИ Тюнинг**.
2. Впишите новые инструкции.
3. Нажмите **Сохранить**. 
4. Все последующие запросы к ИИ (Тьютор и Ассистент) будут использовать эти промпты из базы.

## 6. Устранение ошибок
- **"Missing or insufficient permissions"**: Убедитесь, что вы авторизованы и ваш email подтвержден. Если вы админ, убедитесь, что ваш email совпадает с указанным в `firestore.rules`.
- **Пустая база**: Просто начните пользоваться приложением (создайте новый курс или термин). База заполнится данными мгновенно.
